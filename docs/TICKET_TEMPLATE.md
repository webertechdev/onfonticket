# ONFON 58 mm Ticket Template

The first pilot uses black-and-white thermal printing. The layout is intentionally compact and should target approximately 40–60 mm total length after physical testing.

```text
        ONFON MOBILE
           REPAIR

          REP-014

31/10/2026  10:35 AM
   PLEASE WAIT TO BE CALLED
```

The ticket number is centred, bold, and the dominant element. Do not print the customer's phone number. The service name must always be printed with the ticket number. The service colour is represented in the application and may be added later through pre-coloured stock or a verified colour-capable printer; a normal monochrome thermal printer must not be described as colour-capable.
